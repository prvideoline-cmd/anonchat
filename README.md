# АнонЧат — анонимный чат для Android + свой сервер на VPS

Приложение на Kotlin + Jetpack Compose. Один общий публичный чат в реальном
времени, работает через **ваш собственный сервер на VPS** (папка `server/`
в этом проекте) — никаких сторонних облаков, вся история сообщений
сохраняется на вашем сервере.

При **каждом запуске приложения** пользователю выдаётся новое случайное
тупое и смешное имя (например «ПьяныйПельмень77» или «ДиректорНосатыйЕнот312»)
— имя не сохраняется между запусками. В приложении можно только
переписываться — больше никаких экранов и функций.

## Из чего состоит проект

```
app/      — Android-приложение (Kotlin + Jetpack Compose)
server/   — сервер для вашего VPS (Node.js): WebSocket + REST + история в файле
```

## Шаг 1. Разворачиваем сервер на VPS

Понадобится Node.js 16+ на сервере.

```bash
# на VPS
git clone <ваш-репозиторий> anonchat   # или просто закиньте папку server/ на сервер
cd anonchat/server
npm install
cp .env.example .env
# при желании поправьте .env: PORT, CHAT_SECRET, HISTORY_LIMIT
npm start
```

Сервер поднимется на порту 8080 (или каком укажете в `.env`) и сразу:

- отдаёт историю сообщений: `GET http://ВАШ_IP:8080/api/messages`
- принимает подключения чата: `ws://ВАШ_IP:8080/ws`
- пишет каждое сообщение в файл `server/data/messages.jsonl` — это и есть
  постоянная история чата на вашем VPS (файл никогда не перезаписывается,
  только дополняется).

Чтобы сервер работал постоянно и поднимался после перезагрузки VPS —
используйте `server/anonchat.service` (systemd) или `pm2 start server.js`.

Открыть порт в файрволе (если используете ufw):

```bash
sudo ufw allow 8080/tcp
```

### Про безопасность

По умолчанию сервер открыт всем, кто знает адрес — это ожидаемо для
анонимного публичного чата. Если хотите закрыть его от посторонних людей,
не знающих про приложение:

1. Задайте `CHAT_SECRET` в `server/.env` (любая строка).
2. Впишите то же самое значение в `Config.CHAT_SECRET` в приложении
   (см. шаг 2) — без правильного секрета сервер не пустит ни в чат, ни в
   историю.

Для шифрования соединения (https/wss) — заведите домен, направьте его на
IP сервера и настройте `server/nginx.conf.example` + `certbot` (пример
команды внутри файла). Без этого чат тоже прекрасно работает, но трафик
идёт в открытом виде (обычное дело для внутренних/приятельских чатов, но
учитывайте это).

## Шаг 2. Указываем адрес сервера в приложении

Откройте `app/src/main/java/com/anonchat/app/Config.kt` и впишите свои
данные:

```kotlin
const val SERVER_HOST = "203.0.113.10"   // IP или домен вашего VPS
const val SERVER_PORT = 8080
const val USE_TLS = false                // true, если настроили https/wss через nginx
const val CHAT_SECRET = ""               // такой же секрет, как в server/.env, если включали
```

## Шаг 3. Собираем APK

Готового скомпилированного `.apk` в этой заявке нет по одной причине: в
облачной песочнице, где я работаю, заблокирован доступ к серверам Google
(dl.google.com, maven.google.com) — оттуда Android Studio скачивает
Android SDK, без которого собрать `.apk` физически невозможно. Сам код
полностью готов и рабочий, собрать его — 5–10 минут одним из способов:

### Способ 1 (проще всего, ничего не устанавливать): GitHub Actions

1. Загрузите содержимое этой папки в пустой репозиторий на GitHub
   (workflow `.github/workflows/build-apk.yml` уже настроен и внутри
   проекта).
2. Вкладка **Actions** репозитория — сборка запустится сама, через пару
   минут в разделе **Artifacts** появится готовый `AnonChat-debug-apk`.
3. Скачайте и установите на телефон.

### Способ 2: Android Studio

1. Установите [Android Studio](https://developer.android.com/studio).
2. **File → Open** → откройте папку проекта, дождитесь синхронизации
   Gradle (SDK скачается автоматически).
3. **Build → Build APK(s)** — файл появится в
   `app/build/outputs/apk/debug/app-debug.apk`. Либо сразу ▶ Run на
   подключённый телефон.

## Структура Android-приложения

```
app/src/main/java/com/anonchat/app/
  Config.kt                — адрес вашего VPS-сервера (шаг 2 выше)
  AnonChatApplication.kt   — генерирует новое смешное имя при каждом запуске
  NameGenerator.kt         — генератор тупых и смешных имён
  MainActivity.kt          — экран чата на Jetpack Compose
  ChatViewModel.kt         — состояние экрана
  data/ChatRepository.kt   — WebSocket + REST клиент к вашему серверу
  model/ChatMessage.kt     — модель сообщения
```

## Что делает приложение

- Один общий публичный чат-канал в реальном времени, только переписка —
  никаких других функций и экранов.
- Новое случайное тупое и смешное анонимное имя при каждом запуске
  приложения.
- История сообщений подгружается с вашего сервера при входе.
- История хранится постоянно на вашем VPS в `server/data/messages.jsonl`.
- Простой интерфейс на Material 3: свои сообщения — фиолетовые справа,
  чужие — белые слева, с именем автора и временем.
